# Security Policy

## Discord Security Issues

This is a personal GitHub profile and not an official Discord channel. **Vulnerability reports about Discord's products or services can't be handled here.** Please don't send them to me directly, and please don't open public issues about them.

To report a vulnerability in Discord, use Discord's official channel:

- **Security page:** https://discord.com/security
- **Bug bounty:** Discord runs its security bug bounty on Bugcrowd as a private program. If you aren't already part of it, you can be considered for an invitation by responsibly disclosing a high-impact vulnerability to **bugbounty@discordapp.com**.

Reports sent through Discord's official process reach the team that can actually investigate and fix them. Please follow the program rules on the security page, including these basics:

- Only test against accounts and servers you own, and never affect other users.
- Stay within services Discord directly operates. Third-party services that integrate with Discord's APIs are out of scope.
- Don't run scanners or automated tools, and don't do anything that could harm the reliability or integrity of Discord's services.
- Don't share details publicly until Discord has finished investigating and resolving the issue.

## Not a Security Issue?

For account problems, harassment, scams, or content that violates the rules, use [Discord Support](https://support.discord.com/hc/en-us) or the [Safety Center](https://discord.com/safetycenter) instead.

## My Personal Projects

For vulnerabilities in my own open-source repositories, please report them privately using GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on the affected repository (Security tab → "Report a vulnerability"). I aim to acknowledge reports within a few days and will coordinate disclosure with you.
